# Equation

MonsterEXP(level) = round(100 × 1.15^(level - 1))

EXPRequired(level):
Level 1 = 5 × MonsterEXP(1)
Levels 2–49 = 10 × MonsterEXP(level)
Level 50 = 0, because it is max level
