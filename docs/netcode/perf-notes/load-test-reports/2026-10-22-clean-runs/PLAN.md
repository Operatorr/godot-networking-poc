# Fixed-build correctness campaign

Owned by [Fix load-test-exposed bugs and rerun until a run is clean](https://github.com/Operatorr/godot-networking-poc/issues/39).
The map explicitly authorizes execution and repeated matched runs. This campaign
does not resolve another map ticket or advance drafting before the clean-run gate.

Run the diagnose loop locally first, with failing-before/passing-after regressions.
Each remote workload gets a separate child agent, a unique namespace, immutable
revision and executable hashes. Shared CAX11 hosts run sequentially; verify idle
ownership before starting and restoration before dispatching the next cell.
Preserve all historical binaries, archives, settings and reports. Use bounded
evidence, atomic schedule publication and byte-aware complete journal counts.

First matched cell: Strategy 150 under the last send150 condition (2 MiB requested
receive/send buffers), 30 Hz input, 100 ms stagger, 60 s warmup, 300 s measurement.
The current candidate fixes packet sizing, Baseline ordering and observer evidence;
it is a new condition, not a retrospective upgrade of the prior AoI diagnosis.
Use the repaired bounded wire collector and same per-peer 29.7 Hz validity gates.
The production AoI checker must have no unknown positions and retain its 1150-unit
threshold. An emission audit is additional evidence, never a substitute for receipt.

After matched correctness passes, rerun every previously passing native ladder cell:
Idle 100/150; Movement 50/100/150; Combat 50/100; Clustered 50; Strategy 50/100.
Also run one Strategy overload ramp (200 initially) with actual population,
generator validity, delivery, Tick, backlog and errors retained. Capacity failure
may be a clean characterized limit; a code or measurement defect restarts the loop.
Do not skip a new finding, weaken a gate, or close the ticket after a partial rerun.

The bug ledger records each classification, fix, regression and matched validation,
then explicitly marks earlier results affected by changed behavior or invalid
measurement. All cited article numbers must identify the surviving build/condition.


The ladder stop applies per workload. A failed Idle150 control remains classified
and uncertified while independent required workloads may start at their own first
rung. They retain the existing strict gates. An offered-load versus wire-delivery
classification interpretation is pending; no proposal changes current scoring.
The final ticket still requires the full mandated rerun and findings assessment.
